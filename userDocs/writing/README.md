# Writing text

Descriptions, comments and long text fields are written in a simple way of marking text, called Markdown. You write plain text with a few marks, and Bugaboo shows it as headings, lists, bold text and so on. Everybody sees the same, and nothing a person pastes can run in your browser.

- [What you can write](markdown.md): the marks, the buttons above the text box, the preview, issue IDs and mentions, web addresses and images
