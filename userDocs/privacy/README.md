# Privacy

Bugaboo is built so an organization can run it in line with the GDPR. The organization stays responsible; these pages say what Bugaboo does for it.

- [My data](../my-settings/my-data.md): every person downloads everything Bugaboo stores about them, sees how long each kind is kept and where it is corrected
- [Keep and delete rules](keep-rules-page.md): the page where an administrator sees and changes the keep periods, and deletes the business records past theirs
- [The table of the keep periods](keep-and-delete.md): every kind of data, with the periods a new organization starts with
- [Data exports](data-exports.md): who created which file of whose data, and *Download someone's data*
- [Switch off and remove a person](remove-a-person.md): ending a person's sign-in at once, and removing them for good

Only the cookies needed to stay signed in are used, and nothing is sent to outside services an administrator has not switched on.
