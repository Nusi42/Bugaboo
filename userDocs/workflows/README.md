# Workflows

A **workflow** says which statuses an issue type can have and which status changes are allowed between them. Every issue is in one **status**, and every status belongs to a **status group**: *Not started*, *In progress* or *Done*. Searches, the list and progress read the group, so a workflow can name its statuses as it likes.
