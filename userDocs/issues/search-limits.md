# Limits of a search

GENERATED by `cargo xtask gen api` from the numbers in the code. Do not edit this page by hand.

A search that goes over a limit is told so in plain words below the box, before anything is sent to the server. The limits keep one search from keeping the server busy for everybody.

| What                                     | The most   | Note                                                                     |
| ---------------------------------------- | ---------- | ------------------------------------------------------------------------ |
| Filters in one search                    | 50         | `in (a, b, c)` counts as many filters as it has values.                  |
| Words in one `contains`                  | 10         | A word that comes twice counts once.                                     |
| Keys of `sort by`                        | 5          |                                                                          |
| Steps of `connected to … within N steps` | 5          |                                                                          |
| Brackets inside brackets                 | 32         | `not` counts like a bracket.                                             |
| Length of the text of a search           | 4096 bytes | Letters with accents and other scripts take more than one byte.          |
| Longest word that is looked for          | 255 bytes  | A longer run of letters is not looked up.                                |
| Fewest letters before a `*`              | 2          | `cra*` finds words that start with cra; `c*` is looked up as the word c. |

See [Searching for issues](search.md).
