The current milestone, wave, each work package's state and folder, open questions and the very next action are in `docs/STATUS.md` in the repository (the master's copy is current: the lead fast-forwards `main` after every status update). This memory only points there, so the state is never kept twice.

**Why:** sessions end at any time, and a new one starts in the master and continues from the repository.

**How to apply:** read `docs/STATUS.md` first, then follow "The lead's routine" in `docs/04-milestones.md` (agents of an old session are gone; resume packages marked *building* from their branch and folder).
