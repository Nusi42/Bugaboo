Bugaboo targets German organizations (terms like Kostenstelle, Entwicklung). It must be GDPR-compliant in every feature, and timesheets must record the start and end of each working day (the German working-time recording duty), not only time per issue. Time entries need customizable accounting fields (cost center, activity category).

**Why:** requirement from the UX design review.

**How to apply:** check every new feature for personal-data handling (minimization, retention, export, erasure, visibility). Frame legal features as "supports compliance", not legal advice. Related: [[plain-language-no-vendor-terms]]
