- `mockups/` — clickable mockups ([live](a published page, not linked here)).

## Product priorities (in order)

1. Security first, secure by default
2. UX
3. AI integration
4. Software and design architecture
5. Feature completeness
6. Ease of installation

When two goals conflict, the higher one wins. Record the trade-off in an ADR.
