The first release of Bugaboo to install and run for real: everything an
organization needs to keep its data in order, back it up, run Bugaboo as a
service and know what it installed. It is a free public preview.

## What is new

- **Download my data.** Everybody can download what Bugaboo stores about
  them from *My settings › My data*: one file of readable pages and JSON,
  with a README that says for each kind of record why it is kept, on which
  legal basis, how long and who receives it.
- **Download someone's data.** An administrator with *Download someone's
  data* makes the file for another person under *Organization settings ›
  Privacy › Data exports*, always with a reason; the person is told in
  Bugaboo and by e-mail.
- **Switch off and remove a person.** *Switch off* ends a person's sign-in,
  sessions, keys and agents while everything they did stays theirs.
  *Remove a person* then says what goes, what stays as *Former user* and what
  the law keeps until when (their work days, under their name, for HR).
- **Correct your own data.** People change their name and e-mail address
  in *My settings › Profile*; an administrator corrects them for others with
  a reason.
- **Keep and delete rules.** One page lists how long each kind of data is
  kept and who deletes it. Most of it is deleted by itself after its period;
  work days and time entries are deleted by an administrator with
  *Delete them*.
- **Backups while people work.** *Organization settings › System › Backups*
  creates a backup now or every day, and `bugaboo restore` puts one back
  with the server stopped. A restore signs everybody out and does again
  what must not be undone (people switched off or removed, keys taken back).
- **Upgrades that find their way back.** A new version makes a backup before
  it changes the database, and puts it back if a change fails.
- **Bugaboo as a service** on Windows and on Linux with systemd:
  `bugaboo service install`.
- **Signed releases.** Every file of a release is signed; the installed
  Bugaboo checks a new program with `bugaboo update verify <file>` and warns
  about an older version.
- **The parts list.** Each release carries its parts list (SBOM) in the
  CycloneDX and SPDX formats, the licenses of its parts and why known
  vulnerabilities of parts do not affect Bugaboo; *About* shows the version,
  the support period, the license and the parts, and offers the files.
- **Secure by default.** Nobody outside the organization gets in by default;
  sign-up, every kind of AI and e-mail start off. Bugaboo serves
  `/.well-known/security.txt`, and `SECURITY.md` says how to report a
  vulnerability.
- **Accessibility.** Every screen passed the automatic checks of WCAG 2.2 AA;
  the accessibility statement says what was checked and how.
- **Agents.** Several agents can be created at once, a program can ask for
  agents with a reason, agents wait for work, hand it over, and a person can
  undo what an agent did.

## Known issues

- **Windows refuses the program on a computer with Smart App Control.** The
  Windows program is not signed with a code-signing certificate yet, so
  Windows 11 with *Smart App Control* switched on does not start it, and
  other computers warn about an unknown publisher. Check the signature with
  [Check a download](https://github.com/Nusi42/Bugaboo/blob/main/userDocs/install/verify-a-download.md)
  and follow [Install on Windows](https://github.com/Nusi42/Bugaboo/blob/main/userDocs/install/windows.md).
- **A service installed with 0.5 keeps its old settings.** When only the
  program is replaced, the service keeps the unit or the service settings it
  was installed with. After the upgrade to 0.6, run `bugaboo service
  uninstall` and then `bugaboo service install` once; the data stays where it
  is.
- **No screen reader test by a person yet.** The screens passed the automatic
  checks but were not yet tested by a person with a screen reader; the
  accessibility statement marks those criteria *Not tested by a person*.
- **Restore from the command line only.** *Backups* shows the command; there
  is no button that restores.
- **Windows x64 and Linux x64 only.** Programs for ARM64 come with a later
  release.

## Install or update

- **New installation:** follow [Install Bugaboo](https://github.com/Nusi42/Bugaboo/blob/main/userDocs/install/README.md).
- **Update:** check the new program with the Bugaboo you have installed
  (`bugaboo update verify <file>`), stop the service, replace the program and
  start it again. It makes a backup and brings the database up to date by
  itself ([Update Bugaboo](https://github.com/Nusi42/Bugaboo/blob/main/userDocs/install/upgrade.md)).
- An upgrade keeps AI apps and agents as they were; new installations start
  with both off.
- Windows warns about an unknown publisher until Bugaboo's program is signed
  with a certificate; check the signature first.

## Files

| File | What it is |
|------|------------|
| `bugaboo-{version}-windows-x64.exe` | The program for Windows x64 |
| `bugaboo-{version}-linux-x64` | The program for Linux x64, for every distribution and WSL |
| `bugaboo-{version}.cdx.json`, `bugaboo-{version}.spdx.json` | The parts list in the CycloneDX and SPDX formats |
| `bugaboo-{version}-notices.txt` | The licenses of the parts |
| `bugaboo-{version}.vex.json` | Why known vulnerabilities of parts do not affect Bugaboo |
| `bugaboo-{version}-notes.md` | These notes |
| `SHA256SUMS` | The checksum of each file above |
| `*.minisig` | The signature of each file above and of `SHA256SUMS` |
