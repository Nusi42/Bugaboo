# Glossary of the example

| Say          | Meaning                       | Don't say                |
|--------------|-------------------------------|--------------------------|
| **Sign in**  | Open your use of the program  | log in, login, logout    |
| **Issue**    | Anything that is tracked      | ticket, work item        |
| **Group**    | A set of people               | team (as object)         |
| **Page**     | A document written in it      | —                        |
