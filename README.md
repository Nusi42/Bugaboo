# Bugaboo

A self-hosted, security-first issue tracker: bug tracking, time tracking, workflows,
Gantt planning, custom fields, a query language with a visual builder, and first-class
AI / MCP integration — all configurable from the UI.

- Server: Rust · Frontend: React + TypeScript
- Runs on Windows, Linux and WSL; used from any modern browser, desktop or handheld.
